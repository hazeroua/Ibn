# Les Chemins d'Ibn Khaldoun

Jeu d'action-aventure en monde ouvert, en 3D stylisée sous **Godot 4**, qui suit la vie d'Ibn Khaldoun (1332–1406), de Tunis à Damas.

> **Damas, 1401.** Encerclé par l'armée de Tamerlan, un vieil historien se fait descendre par une corde le long des remparts pour affronter le conquérant. Pour sauver la ville, il va lui raconter sa vie.
