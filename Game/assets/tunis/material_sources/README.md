# Matériaux de la médina

Ces quatre images sont des sources [Poly Haven sous licence CC0](https://polyhaven.com/license), réduites dans l'atlas de couleurs intégré aux modules GLB. Le jeu n'interroge pas l'API de Poly Haven. Les modèles et la composition de l'atlas sont produits par `Scripts/Blender/generer_architecture_tunis.py`.

| Fichier | Source | Auteur |
| --- | --- | --- |
| `patterned_clay_plaster.jpg` | [Patterned Clay Plaster](https://polyhaven.com/a/patterned_clay_plaster) | Amal Kumar |
| `white_rough_plaster.jpg` | [White Rough Plaster](https://polyhaven.com/a/white_rough_plaster) | Rob Tuytel |
| `white_sandstone_bricks.jpg` | [White Sandstone Bricks](https://polyhaven.com/a/white_sandstone_bricks) | Poly Haven |
| `rough_wood.jpg` | [Rough Wood](https://polyhaven.com/a/rough_wood) | Poly Haven |

Le choix des formes part de [l'Atlas du patrimoine urbain de l'UNESCO pour Tunis](https://whc.unesco.org/fr/atlas-patrimoine-urbain/tunis/) : maisons à cour, remparts, portes, passages couverts et minarets. Les modèles sont une interprétation pour le jeu, pas des relevés de monuments précis.
