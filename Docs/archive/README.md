# Archives de l'ancien projet

Ce dossier conserve les décisions, contrats et mesures antérieurs au reboot Terrain3D du 21 novembre 2026.

Ces documents servent uniquement à comprendre l'historique. Ils ne définissent ni le périmètre actuel, ni l'architecture, ni les critères de fermeture des tickets #62 à #68.

## Contenu

- `roadmap-mvp-legacy.md` : ancienne roadmap des MVP 0 à 17 ;
- `contrats-mvp-*.md` : contrats techniques des anciens MVP ;
- `medina-generation.md` : ancien générateur et format de Tunis ;
- `performance-intel-arc-legacy.md` : mesures de l'ancien désert ;
- `remarques-mvp-2.md`, `reste-a-faire-*.md` : analyses et travaux restants abandonnés avec l'ancien socle.

Une information archivée ne peut être réintroduite qu'après une décision explicite et une validation sur le nouveau projet.
